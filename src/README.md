# Исходники Data Sheet Editor

Рабочая (не собранная) версия редактора. В корне репозитория лежит
`index.html` — тот же редактор, собранный в один автономный файл для
GitHub Pages.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | разметка страницы и диалоги |
| `styles.css` | стили интерфейса |
| `app.js` | состояние, проекты и листы, правка таблицы, эталон, хранение |
| `xlsx.js` | генератор книги Excel (OOXML + ZIP без внешних библиотек) |
| `seed.js` | данные 17 приборов эталона, рисунки в base64 (2,8 МБ) |
| `actions.json` | сценарий браузерной проверки |

`seed.js` на GitHub не откроется в просмотрщике — файл больше 1 МБ, в нём
в основном изображения. Это нормально: код правится в остальных файлах.

## Запуск без сборки

Открыть `index.html` из этой папки в браузере — обычная многофайловая
страница, все скрипты и стили подключаются относительными путями.

## Сборка одного файла для сайта

Из папки `src`:

```text
multitool-node --skill websites site.cjs bundle index.html ..\index.html
multitool-node --skill websites site.cjs check ..\index.html
```

Бандлер встраивает `styles.css`, `app.js`, `xlsx.js`, `seed.js` внутрь HTML.
Проверка интерфейса:

```text
multitool-node --skill websites verify.cjs ..\index.html --actions actions.json
```

## Правка и публикация

Основные исходники ведутся в рабочей папке проекта `ds-editor`; сюда они
выкладываются копией. После правки `src/` пересоберите корневой `index.html`
командой выше и закоммитьте оба изменения — иначе сайт и исходники разойдутся.
