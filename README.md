# Data Sheet Editor

Онлайн-редактор листов технических данных КИП.

Один самодостаточный файл `index.html` — данные приборов, рисунки и генератор
Excel упакованы внутрь, внешние библиотеки и сеть не нужны.

## Что умеет

- Проекты и листы внутри проекта; эталонный проект «Все листы» защищён от
  случайной правки (включается подтверждением).
- Добавление листов из эталона: галочками, «Выбрать всё», несколько за раз.
- Кнопка «Привести к эталону» — вернуть лист к эталонной версии.
- Хранение: IndexedDB + localStorage в браузере, плюс кнопки «Сохранить файл»
  и «Открыть файл» (`.json`).
- Выгрузка книги Excel: листы RU/EN/TAG, A4, масштаб 89 %, рисунки, теги.

## Как открыть

`index.html` открывается локально в браузере или публикуется через GitHub Pages.
Данные хранятся в браузере пользователя; для переноса между компьютерами
используйте «Сохранить файл» / «Открыть файл».

Исходники — в папке [`src/`](src/README.md): `app.js`, `styles.css`, `xlsx.js`,
`seed.js` и шаблон `index.html`. GitHub не показывает `index.html` в корне и
`seed.js` в просмотрщике: файлы весят больше 1 МБ (внутри — вшитые данные и
рисунки), поэтому код смотрите в файлах `src/`, а страницу — по адресу сайта
или через `Raw`.
