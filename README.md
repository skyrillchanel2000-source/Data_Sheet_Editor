# Data Sheet Editor

Онлайн-редактор листов технических данных КИП. Обычный статический сайт:
HTML, CSS, JS, данные в JSON и рисунки отдельными файлами.

Сайт: https://skyrillchanel2000-source.github.io/Data_Sheet_Editor/

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | страница и диалоги |
| `styles.css` | стили интерфейса |
| `app.js` | проекты, листы, таблица, эталон, хранение |
| `xlsx.js` | сборка книги Excel (OOXML + ZIP без внешних библиотек) |
| `seed.json` | данные 17 приборов эталона «Все листы» |
| `seed.js` | тот же JSON в обёртке `window.DS_SEED = …;` — чтобы страница работала по `file://` без сервера |
| `img/` | рисунки приборов (22 файла, JPG) |
| `tools/make_seed_js.py` | пересборка `seed.js` из `seed.json` |

## Локальный запуск

Открыть `index.html` из этой папки в браузере. Для выгрузки Excel с рисунками
нужен адрес `http(s)`, а не `file://`: рисунки подтягиваются по путям через
`fetch`. Проще всего открыть сайт выше или поднять локальный сервер:

```text
python -m http.server 8000
```

и зайти на http://localhost:8000/

## Правка данных

`seed.json` правится вручную или пересобирается из эталонной книги. После
изменения данных пересоберите обёртку и закоммитьте оба файла:

```text
python tools/make_seed_js.py
```

## Возможности

- Проекты и листы; эталонный проект «Все листы» защищён от случайной правки,
  включение правки — только с подтверждением.
- Добавление листов из эталона галочками, «Выбрать всё», несколько за раз.
- «Привести к эталону» — вернуть лист к эталонной версии.
- Хранение: IndexedDB + localStorage, плюс «Сохранить файл» / «Открыть файл»
  (`.json`).
- Выгрузка книги Excel: листы RU/EN/TAG, A4, масштаб 89 %, рисунки, теги.
